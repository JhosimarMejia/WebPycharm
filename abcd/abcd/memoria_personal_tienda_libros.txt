MEMORIA PERSONAL – Proyecto Tienda de Libros

1.  Estado actual del proyecto

Arquitectura conseguida: - Interfaz: Python + curses - Sistema de
archivos: Bash - Datos: JSON - Estructura persistente:
/tiendas/tienda_libros

Separación lograda: - Python: interacción y validación lógica básica. -
Bash: creación y eliminación física de archivos y directorios. - JSON:
almacenamiento estructurado de datos.

El proyecto cumple la filosofía solicitada en clase.

------------------------------------------------------------------------

2.  Aspectos que ya entiendo y debo poder explicar

Normalización de nombres: - Elimina espacios externos. - Convierte a
minúsculas. - Quita acentos. - Sustituye espacios por guiones bajos. -
Evita duplicados invisibles por mayúsculas o acentos.

Generación de ISBN: - Uso de contador.txt. - Lectura → incremento →
escritura. - Formato: 978000001.

Comunicación Python ↔ Bash: - Uso de subprocess.run(). - Bash devuelve
códigos de salida. - Python interpreta el returncode. - Bash imprime
“CREADO|ruta”. - Python separa con split(“|”).

------------------------------------------------------------------------

3.  Aspectos que necesito indagar más

Curses: - curses.LINES y curses.COLS. - Manejo de scroll manual
(offset). - echo() vs noecho(). - Funcionamiento interno de cbreak().

Códigos de retorno en Bash: - Diferencia entre exit 1 y exit 30. -
Buenas prácticas al definir códigos personalizados. - Interpretación
correcta de returncode en Python.

Manejo seguro de JSON: - Qué ocurre si el JSON está corrupto. -
Validación de estructura. - Añadir nuevos campos sin romper
compatibilidad.

Seguridad de rutas: - Qué es path traversal. - Uso correcto de
relative_to(). - Limitación del explorador para evitar salir de la base.

Permisos en Linux: - Diferencia entre 755 y 777. - Significado de rwx. -
Qué es umask. - Buenas prácticas de permisos.
